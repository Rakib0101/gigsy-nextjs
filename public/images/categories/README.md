# Category Images

This folder contains all category images for the mega menu.

## Image Requirements

- **Size**: Recommended 100x100px (or square aspect ratio)
- **Format**: JPG, PNG, or WebP
- **Naming Convention**: Use the naming pattern shown in the categories data file

## How to Add Images

1. Place your category images in this folder
2. Name them according to the slug pattern used in `data/categories.ts`
3. The mega menu will automatically display them
4. Images will show with a hover zoom effect

## Tips

- Use consistent styling for all category images
- Consider using product photographs or representative icons
- Keep file sizes optimized for web (under 50KB per image)
- Use transparent backgrounds or white backgrounds for consistency
